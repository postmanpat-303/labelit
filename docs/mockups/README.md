# Design mockups

Early UI concepts — static HTML you can open in a browser. These are direction-setters, not specs.

| File | Screen |
|---|---|
| `designer.html` | Main designer: canvas with rulers, element rail, variable-driven property panel, batch filmstrip, printer status in the top bar |
| `gallery.html` | Label-size library: searchable standard sizes by brand/use-case + custom-size editor entry point |
| `batch.html` | Batch data entry: spreadsheet grid with column→`{{variable}}` mapping, live preview, print queue |

Design language: dark shell, single lime accent (`#b8f53d`), the label artboard is the only white surface. Monospace for measurements. Everything keyboard-reachable.

Screenshots of the current iteration are posted in the project discussions/README once the scaffold lands.
